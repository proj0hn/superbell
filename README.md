# 🔔 SuperBell — 매장·물류 현장 재고 정합성 자동 점검

**사진 한 장으로 밀집된 상품을 세어, 장부와 실물의 차이를 잡아냅니다.**

## 문제 — 재고 장부와 실물은 상시 어긋난다

유통 현장의 재고 오차는 두 지점에서 만들어집니다.

**① 입고 검수** — 점포·물류센터는 납품 상자를 열어 품목별 수량을 **손으로 셉니다.**
편의점 기준 하루 2~3회 납품, 회당 수십 SKU. 피크 시간과 겹치면 검수가 생략되거나 눈대중으로 끝나고,
오배송·수량 부족이 그대로 "정상 입고"로 장부에 올라갑니다. **이 순간부터 재고 데이터 자체가 틀립니다.**

**② 진열 결품** — 장부엔 재고가 있는데 매대는 비어 있는 상태(phantom inventory)를
직원이 수천 SKU의 매대를 **눈으로 훑어** 찾습니다. 진열 결품만으로 유통사 연매출의 약 **8%** 가 손실되고,
AI 컴퓨터비전 OSA 시장은 2026년 **68.5억 달러**(CAGR 8.7%) 규모입니다.

두 작업은 결국 **"밀집돼 놓인 상품을 사람이 눈으로 센다"** 는 동일 작업입니다.
그래서 **하나의 계수 모델로 두 지점을 동시에 자동화**합니다.

## 두 개의 모드

| | 모드① 입고 검수 대조 | 모드② 진열 결품 점검 |
|---|---|---|
| 입력 | 검수대에 펼친 상품 사진 | 매대 정면 사진 |
| 처리 | 카테고리별 수량 집계 → **발주 수량과 대조** | 페이싱 계수 → **기준 진열량과 대조** |
| 출력 | 과부족 하이라이트 + 검수 리포트(.md) | 잔여율 · 결품/부족 경보 · 보충 우선순위 |
| 모델 | `superbell_intake.pt` (RPC · 17 카테고리) | `superbell_shelf.pt` (서울시 국내 진열대 · 5 매대 카테고리) |

> **설계 원칙:** AI는 **"센다"까지만** 하고, 판단은 **기준값과의 대조(rule)** 가 합니다.
> 계수는 검증 가능한 지표(cAcc·MAE·RMSE)로 정량화되고, 대조는 현장이 이미 갖고 있는 데이터
> (발주서·기준 진열량)에 붙습니다.

## 성능

**모드① — RPC 평가셋 90장 (학습 미사용)**

| 모델 | cAcc↑ | MAE↓ | RMSE↓ | 종류 |
|---|---|---|---|---|
| ZERO 제로샷 (baseline) | 0.178 | 3.944 | 5.176 | ✗ |
| **SuperBell (YOLO11s 파인튜닝)** | **0.678** | **0.467** | **0.943** | ✓ (17 카테고리) |

밀집(hard) 구간에서 이득이 가장 큽니다 — MAE **6.357 → 0.429**.

> **cAcc가 왜 중요한가:** 입고 검수는 "몇 개쯤"이 아니라 **"발주 수량과 정확히 같은가"** 를 판정하는 작업입니다.
> 평균 오차가 작아도 한 장이라도 틀리면 검수는 실패입니다. **cAcc(개수 완전 일치 비율) = 검수 자동화 성공률**입니다.

**모드② — 서울시 진열대 val 178장** (학습 완료 후 사이드바에 자동 표시)

## 파이프라인 (Superb AI Suite 4단계 × 2사이클)

```
데이터 선별 → 라벨링(GT import · Auto-Label + 사람 검수) → 스냅샷·학습·배포 → 서비스
  RPC 300장         RPC/SKU110K/서울시 GT import              YOLO11s 파인튜닝     본 웹앱
  서울시 898장       AI Hub 2,000장 전수 검수                   ZERO 제로샷 비교
```

## 데이터 · 라이선스

- **RPC** (Retail Product Checkout) — CC BY-NC-SA 4.0 · 모드① 학습·평가 300장 / 3,623박스
- **서울시 상품 표지 이미지** — 공공데이터 개방(출처표시) · 모드② 학습 898장 / 7,754박스
- **AI Hub 상품 이미지** — AI Hub 이용약관 · 국내 도메인 보강 2,000장 전수 검수
- **SKU110K** — 연구·비상업 공개 · 밀집 한계 시험(학습 보류, 라벨은 유효 자산)

## 한계 (정직하게)

- 발주 수량·기준 진열량은 **데모용 입력값**입니다. 실서비스에서는 **WMS 발주서·플래노그램**과 연동됩니다.
- SKU110K(장당 ~145박스) 초밀집 구간은 학습이 OOM으로 보류돼 **커버하지 않습니다.**
- 모드①은 **평면 top-down 촬영** 기준입니다. 파렛트·롤테이너 적재 상태는 하단 가림(occlusion)으로 셀 수 없습니다.

본 데모는 **비상업 연구·교육 목적**입니다.
